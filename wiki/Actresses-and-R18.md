# Actresses and R18

The Actresses tab is built around imported R18 actress and work metadata.

## Actress List

Use the actress list to browse imported actresses, favorite entries, and open details for a selected actress.

## Display Aliases

SceneWhisper can show browser-local custom display aliases for actresses. These aliases affect labels in the UI but do not change imported R18 data.

## Works

An actress detail view can show works with metadata such as:

- Content ID, DVD ID, or video code
- English or Japanese title
- Release date
- Cover image
- Local file state
- Censored, uncensored, subtitled, and resolution flags

## Local File State

Works can be compared against local indexed files. This helps identify present, missing, and previously deleted videos.

## Downloads

SceneWhisper can integrate with qBittorrent for work download workflows. Configure qBittorrent connection settings in Settings before using download actions.

Download queue behavior can be controlled with:

- Base delay
- Random jitter
- UTC download window
- Download time limit

## Actress Download Monitors

Actress download monitors can periodically check selected actress criteria and queue matching downloads.

Criteria can include search text, sort order, local file state, censored/uncensored/subtitled flags, resolution, and release year.
