# File Browser

The All Files tab is the main view for scanned media. It shows indexed videos, processing state, metadata, and file actions.

## Layouts

SceneWhisper supports grid and folder-style layouts. The default layout can be changed in Settings. File Browser state is URL-visible so filtered views can be refreshed or shared.

## Searching and Filtering

Use search and filters to narrow large libraries. Available filters include:

- File type and format
- Directory include or exclude
- Date range
- Processing coverage such as has scenes, has split, has subtitle, or missing those outputs
- Scene count
- File status
- Queue disabled, split disabled, or subtitle disabled
- Number-suffix checks
- New video checks
- Content tags such as censored, uncensored, and subtitled
- Resolution buckets, including `480p and below`
- File size comparisons

Saved filters can be reused for common views.

## Sorting and Pagination

Files can be sorted by common fields such as name, size, created date, and modified date. Pagination controls keep large libraries manageable.

## File Actions

Actions depend on the file state, but common workflows include:

- Queue processing tasks
- View file information
- Open task history for a file
- Rename a file
- Open scenes in the Scene Viewer
- Open or edit subtitles
- Delete file records or physical files when available
- Disable queue, split, or subtitle actions for a file

## Scene Viewer

Files with detected scenes can be opened in the Scene Viewer. The viewer is used for reviewing scene cuts and navigating through detected scene ranges.

## Subtitle Editor

Files with subtitles can be opened in the subtitle editor. Subtitle tools also exist under Tools for broader subtitle health checks.

## Grouped Results

The grouped file views collect similar files together. Grouped cards are useful when comparing variants or duplicates inside the library.
